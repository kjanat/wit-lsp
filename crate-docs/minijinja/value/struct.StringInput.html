Struct StringInput

pub struct StringInput<'a> { /* private fields */ }
Expand description

A string coerced from a value together with its safety provenance.

StringInput can be used as an argument to filters and functions when a string transformation needs to account for whether the input value was marked safe. Unlike String and Cow<str>, it retains that information during argument conversion.

It intentionally does not dereference to str, since doing so would make it easy to apply a string transformation and accidentally discard the safety provenance.

use minijinja::value::StringInput;

fn shout(value: StringInput<'_>) -> Value {
    let output = value.as_str().to_uppercase();
    value.preserve_safety(output)
}

env.add_filter("shout", shout);

This should only be used when the output is derived entirely from this input and does not introduce other potentially unsafe content.
