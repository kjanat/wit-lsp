Struct SyntaxConfigBuilder 

Source 
pub struct SyntaxConfigBuilder { /* private fields */ }
Expand description

Builder helper to reconfigure the syntax.

A new builder is returned by SyntaxConfig::builder. To modify an existing configuration use SyntaxConfig::to_builder.

Remove leading spaces and tabs from the start of a line to a block.

pub fn keep_trailing_newline(&mut self, yes: bool) -> &mut Self

Preserve the trailing newline when rendering templates.

The default is false, which causes a single newline, if present, to be stripped from the end of the template.
