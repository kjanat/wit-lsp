Struct TemplateSource 

Source 
pub struct TemplateSource { /* private fields */ }
Expand description

The source of a template as returned by a loader.

A loader registered with Environment::set_loader can either return the template source as a String or as a TemplateSource. The latter allows attaching an up-to-date check with with_uptodate_check which is used to automatically reload templates when auto reloading is enabled.

let changed = Arc::new(AtomicBool::new(false));
let mut env = Environment::new();
env.set_loader({
    let changed = changed.clone();
    move |name| {
        let changed = changed.clone();
        Ok(Some(
            TemplateSource::new(format!("Hello from {name}!"))
                .with_uptodate_check(move || !changed.swap(false, Ordering::Relaxed)),
        ))
    }
});

pub fn with_uptodate_check<F>(self, f: F) -> TemplateSource
where F: Fn() -> bool + Send + Sync + 'static,

Attaches a check that reports if the loaded template is still up to date.

When auto reloading is enabled (the default) the environment invokes this callback every time the template is looked up. If the callback returns false the loader is invoked again to load a fresh version of the template.
